# IMPACT MEASUREMENT FRAMEWORK

No pilot has run. This framework defines what a future
controlled pilot MUST measure before any impact claim:

1. Detection precision/recall on labelled synthetic + lawful
   test data (never real customer data without agreements).
2. False-positive rate vs the institution's current baseline.
3. Median investigation time per case (before/after).
4. Evidence completeness: % cases with full provenance chain.
5. Explanation quality: investigator-rated groundedness of AI
   summaries (sampled, blind).
6. Decision traceability: % decisions with linked evidence +
   audit record (target 100% by construction).
7. System availability + API reliability during pilot.
8. Investigator satisfaction (survey).

Success thresholds, sample sizes and review gates belong in
the pilot plan (docs/PHASE_15_CONTROLLED_PILOT_PLAN.md).
Until then, every benefit statement in this repo is a
projection, explicitly labelled as such.
