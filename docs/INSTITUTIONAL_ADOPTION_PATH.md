# INSTITUTIONAL ADOPTION PATH

Stages (none started — planning only):

0. DEMO (current): synthetic data, protected login, free-tier
   hosting design. No real data, no connectors.
1. DESIGN PARTNERSHIP: written sponsorship, scope, lawful
   test data, DPIA, data-sharing agreements.
2. CONTROLLED PILOT: limited users, success metrics from
   IMPACT_MEASUREMENT_FRAMEWORK.md, exit criteria, rollback.
3. HARDENING: multi-tenancy, RBAC maturity, retention/
   deletion, key rotation, SOC/audit review, model-risk
   validation per docs/PHASE_15_MODEL_RISK_FRAMEWORK.md.
4. PRODUCTION GATE: regulatory + security + exec approvals
   (docs/PHASE_15_PRODUCTION_READINESS_MATRIX.md).

Integration surface (designed, not built):
core banking, PSPs, KYC/identity, AML case management,
sanctions/watchlists, data warehouse — contracts in
docs/PHASE_15_INTEGRATION_ARCHITECTURE.md. No connection
attempts have been made.
